# CodingTest

採用試験用コーディングテスト

LeetCode、AlgoExpertを参考に作成。

> [!NOTE]
> このリポジトリは**公開用のサンプル**です。実際の採用試験で使用する問題全体のうち、一部だけを掲載しています。

## 構成

| ディレクトリ | 内容 | 対象 |
|---|---|---|
| [InterviewGuide](InterviewGuide/README.md) | 面接の進め方・時間配分・評価基準 | 面接官 |
| [CodeReviews](CodeReviews/README.md) | 短いコードを読み、問題点の指摘・修正・改善提案をする問題 | 出題 |
| [AlgorithmQuestions](AlgorithmQuestions/README.md) | データ構造とアルゴリズムの問題 | 出題 |

使用言語は問わない。出題コードと参考実装は JavaScript で書いている。
想定解答も公開しているため、正解を知っているかではなく、対話の中で考え方を説明できるかを評価する。
