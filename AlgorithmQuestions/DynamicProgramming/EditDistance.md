# EditDistance（編集距離）

難易度: ★★★ / 想定時間: 30分 / カテゴリ: [DynamicProgramming](README.md)

## 問題

2つの文字列 `a` と `b` が与えられる。次の3つの操作を繰り返して `a` を `b` に変えるとき、必要な操作の最小回数（レーベンシュタイン距離）を返す。

* 1文字を挿入する
* 1文字を削除する
* 1文字を別の文字に置き換える

## 入出力例

| 入力 | 出力 | 操作の例 |
|---|---|---|
| `a = "kitten"`, `b = "sitting"` | `3` | k→s 置換、e→i 置換、末尾に g を挿入 |
| `a = "horse"`, `b = "ros"` | `3` | h→r 置換、r を削除、e を削除 |
| `a = ""`, `b = "abc"` | `3` | 3文字挿入 |
| `a = "same"`, `b = "same"` | `0` | |

## ヒント

1. `a` の先頭 i 文字を、`b` の先頭 j 文字に変える最小回数を `d[i][j]` とする
2. `a` の i 文字目と `b` の j 文字目が同じなら？ 違うなら、最後の操作は3つのどれか？
3. 空文字列から / 空文字列への距離は、文字数そのもの

## 解答方針

`d[i][j]` = `a` の先頭 i 文字を `b` の先頭 j 文字に変える最小回数

* `d[i][0] = i`（i 文字すべて削除）、`d[0][j] = j`（j 文字すべて挿入）
* `a[i-1] === b[j-1]` なら、最後の文字は操作不要: `d[i][j] = d[i-1][j-1]`
* 違うなら、最後の操作で場合分けして最小をとる

```
d[i][j] = 1 + min(
    d[i-1][j],     // a の i 文字目を削除
    d[i][j-1],     // b の j 文字目を挿入
    d[i-1][j-1],   // a の i 文字目を b の j 文字目に置換
)
```

表を左上から順に埋めて、`d[n][m]` が答え。時間・空間とも **O(n × m)**。

`"horse"` → `"ros"` の表:

|   | "" | r | o | s |
|---|---|---|---|---|
| "" | 0 | 1 | 2 | 3 |
| h | 1 | 1 | 2 | 3 |
| o | 2 | 2 | 1 | 2 |
| r | 3 | 2 | 2 | 2 |
| s | 4 | 3 | 3 | 2 |
| e | 5 | 4 | 4 | **3** |

## 参考実装

```js
function editDistance(a, b) {
    const n = a.length
    const m = b.length
    const d = Array.from({ length: n + 1 }, () => Array(m + 1).fill(0))

    for (let i = 0; i <= n; i++) d[i][0] = i
    for (let j = 0; j <= m; j++) d[0][j] = j

    for (let i = 1; i <= n; i++) {
        for (let j = 1; j <= m; j++) {
            if (a[i - 1] === b[j - 1]) {
                d[i][j] = d[i - 1][j - 1]
            } else {
                d[i][j] = 1 + Math.min(d[i - 1][j], d[i][j - 1], d[i - 1][j - 1])
            }
        }
    }
    return d[n][m]
}
```

## 深掘り質問

* 空間を O(min(n, m)) に減らすには？
  * 各行は直前の行しか使わないので、2行分（または1行分）の配列で足りる
* 実際の操作の手順を出力するには？
  * 表を `d[n][m]` から逆にたどり、どの操作を選んだかを復元する
* 実務ではどんな場面で使われますか？
  * スペルチェックの候補提示、`git diff` などの差分表示、DNA 配列の比較
* 隣り合う2文字の入れ替えも1回の操作とするなら？
  * ダメラウ・レーベンシュタイン距離。`d[i-2][j-2] + 1` の場合を加える
