# ClimbingStairs（階段の上り方）

難易度: ★ / 想定時間: 15〜20分 / カテゴリ: [DynamicProgramming](README.md)

## 問題

n 段の階段がある。1回に 1段 か 2段 上れる。頂上（n 段目）までの上り方が何通りあるかを返す。n は 1 以上。

## 入出力例

| 入力 | 出力 | 内訳 |
|---|---|---|
| `n = 1` | `1` | 1 |
| `n = 2` | `2` | 1+1, 2 |
| `n = 3` | `3` | 1+1+1, 1+2, 2+1 |
| `n = 5` | `8` | |

## ヒント

1. n 段目に着く直前、どこにいたか？
2. n 段目への上り方の数を、n-1 段目と n-2 段目の上り方の数で表すと？
3. そのまま再帰で書くと、同じ計算を何度もしていないか？

## 解答方針

n 段目に着く直前は、n-1 段目（そこから1段）か n-2 段目（そこから2段）のどちらか。よって

```
ways(n) = ways(n - 1) + ways(n - 2)
ways(1) = 1, ways(2) = 2
```

これはフィボナッチ数列と同じ形。

| 方法 | 時間 | 空間 |
|---|---|---|
| 式をそのまま再帰で書く | O(2ⁿ) | O(n) |
| 再帰 + 計算済みの値を記録（メモ化） | O(n) | O(n) |
| 小さい n から順に表を埋める | O(n) | O(n) |
| 直前の2つだけを覚えて計算する | O(n) | O(1) |

素朴な再帰では `ways(n-2)` を `ways(n)` と `ways(n-1)` の両方から計算するなど、同じ計算が指数的に増える。

## 参考実装

```js
function climbStairs(n) {
    let prev = 1  // ways(i - 2)
    let curr = 1  // ways(i - 1)
    for (let i = 2; i <= n; i++) {
        ;[prev, curr] = [curr, prev + curr]
    }
    return curr
}
```

`ways(0) = 1`（何もしない上り方が1通り）とみなすと、`n = 1` から同じ式で扱える。

## 深掘り質問

* 1段・2段・3段のどれかで上れる場合は？
  * `ways(n) = ways(n-1) + ways(n-2) + ways(n-3)`
* 上れる段数が配列 `steps` で与えられる場合は？
* n が 10⁹ のように非常に大きい場合は？
  * 答えが巨大になるので、ある数で割った余りを求めることになる。行列の累乗を使えば O(log n)
