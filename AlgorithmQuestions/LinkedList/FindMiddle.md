# FindMiddle（中央のノード）

難易度: ★ / 想定時間: 15分 / カテゴリ: [LinkedList](README.md)

## 問題

単方向リストの先頭ノード `head` が与えられる。中央のノードを返す。

* 長さが偶数のときは、中央の2つのうち**後ろ側**を返す
* リストを1回だけ走査すること（長さを先に数えてから半分進む、は不可）

## 入出力例

| 入力 | 出力 |
|---|---|
| `1 → 2 → 3 → 4 → 5` | `3` |
| `1 → 2 → 3 → 4` | `3` |
| `1` | `1` |

## ヒント

1. 2回走査してよいなら簡単。1回で済ませるには？
2. 進む速さの違う2つのポインタを使う
3. 速い方が末尾に着いたとき、遅い方はどこにいるか？

## 解答方針

| 方法 | 時間 | 空間 | 走査 |
|---|---|---|---|
| 長さを数えてから、半分まで進む | O(n) | O(1) | 2回 |
| 全ノードを配列に入れ、中央を取り出す | O(n) | O(n) | 1回 |
| 1つずつ進む `slow` と、2つずつ進む `fast` を使う | O(n) | O(1) | 1回 |

`fast` が末尾に着いたとき、`slow` はちょうど半分の位置にいる。

## 参考実装

```js
function findMiddle(head) {
    let slow = head
    let fast = head
    while (fast !== null && fast.next !== null) {
        slow = slow.next
        fast = fast.next.next
    }
    return slow
}
```

## 深掘り質問

* 偶数のとき前側の中央を返すには、どう変えますか？
  * ループ条件を `fast.next !== null && fast.next.next !== null` にする
* `head` が `null`（空のリスト）のときはどうなりますか？
* この「速いポインタと遅いポインタ」は、他にどんな問題に使えますか？
  * 循環の検出（[DetectCycle](DetectCycle.md)）、末尾から k 番目のノード
