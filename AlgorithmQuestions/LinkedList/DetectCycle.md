# DetectCycle（循環の検出）

難易度: ★★ / 想定時間: 25分 / カテゴリ: [LinkedList](README.md)

## 問題

単方向リストの先頭ノード `head` が与えられる。

1. リストに循環（末尾がリストの途中のノードを指している）があるかを判定する
2. 循環があれば、循環が始まるノードを返す。なければ `null` を返す

追加のメモリは O(1) に抑えること。

## 入出力例

```
1 → 2 → 3 → 4 → 5
        ↑       │
        └───────┘
```

| 入力 | 出力 |
|---|---|
| 上図（5 の次が 3） | ノード `3` |
| `1 → 2 → 3`（循環なし） | `null` |
| `1` の次が自分自身 | ノード `1` |

## ヒント

1. 訪れたノードを記録すれば判定できる。メモリを使わずにできないか？
2. 速さの違う2つのポインタは、循環があればいつか出会う
3. 出会った地点から先頭と同じ距離を進むと、循環の開始点に着く

## 解答方針

| 方法 | 時間 | 空間 |
|---|---|---|
| 訪れたノードをハッシュセットに記録する | O(n) | O(n) |
| フロイドの循環検出法（ウサギとカメ） | O(n) | O(1) |

### フロイドの循環検出法

1. `slow` は1つずつ、`fast` は2つずつ進める。`fast` が末尾に着けば循環なし
2. 循環があれば、2つは循環の中で必ず出会う
3. 出会ったら、片方を `head` に戻し、両方を1つずつ進める。次に出会うノードが循環の開始点

### 3 が成り立つ理由

先頭から循環の開始点までの距離を a、開始点から出会った地点までを b、循環の長さを c とする。

* `slow` が進んだ距離: a + b
* `fast` が進んだ距離: a + b + k·c（k 周多く回っている）
* `fast` は `slow` の2倍進むので、2(a + b) = a + b + k·c、つまり **a = k·c - b**

出会った地点から a 進むと「k 周 - b」進むことになり、ちょうど開始点に戻る。

## 参考実装

```js
function detectCycle(head) {
    let slow = head
    let fast = head
    while (fast !== null && fast.next !== null) {
        slow = slow.next
        fast = fast.next.next
        if (slow === fast) {
            let p = head
            while (p !== slow) {
                p = p.next
                slow = slow.next
            }
            return p
        }
    }
    return null
}
```
