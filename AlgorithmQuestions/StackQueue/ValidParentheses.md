# ValidParentheses（括弧の対応）

難易度: ★ / 想定時間: 15分 / カテゴリ: [StackQueue](README.md)

## 問題

`()`、`[]`、`{}` の6種類の文字だけからなる文字列が与えられる。括弧の対応が正しければ `true` を返す。

* 開き括弧は、同じ種類の閉じ括弧で閉じられる
* 括弧は正しい順序で閉じられる（`([)]` は不可）
* 空文字列は `true`

## 入出力例

| 入力 | 出力 |
|---|---|
| `"()[]{}"` | `true` |
| `"{[()]}"` | `true` |
| `"([)]"` | `false` |
| `"(("` | `false` |
| `")("` | `false` |

## ヒント

1. 括弧が1種類だけなら、カウンタで判定できる。3種類ではなぜダメか？
2. 閉じ括弧が来たとき、対応すべきなのはどの開き括弧か？
3. 最後に開いた括弧から順に閉じる → スタック

## 解答方針

* 開き括弧はスタックに積む
* 閉じ括弧が来たら、スタックの一番上が対応する開き括弧なら取り出す。違う（または空）なら `false`
* 最後にスタックが空なら `true`（開いたままの括弧がない）

時間 O(n)、空間 O(n)。

## 参考実装

```js
function isValidParentheses(s) {
    const pairs = { ')': '(', ']': '[', '}': '{' }
    const stack = []
    for (const ch of s) {
        if (ch === '(' || ch === '[' || ch === '{') {
            stack.push(ch)
        } else if (stack.pop() !== pairs[ch]) {
            return false
        }
    }
    return stack.length === 0
}
```

空のスタックで `pop()` すると `undefined` が返るので、`)(` のような入力も `false` になる。
