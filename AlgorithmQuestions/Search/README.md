# Search

## 問題一覧

| 問題 | 難易度 | 目標計算量 | 詳細 |
|---|---|---|---|
| ソート済み配列から値を探す（バイナリサーチ） | ★ | 時間 O(log n) | [BinarySearch](BinarySearch.md) |
| 迷路のスタートからゴールまでの最短距離を求める（BFS） | ★★ | 時間 O(H × W) | [GridShortestPath](GridShortestPath.md) |
| グリッド上の島（つながった陸地）の数を数える（DFS / BFS） | ★★ | 時間 O(H × W) | |
| 文字列の中からパターンを探す（力技 / KMP 法 / BM 法） | ★★〜★★★ | 時間 O(n + m)（KMP） | |
| 重み付きグラフの最短経路を求める（ダイクストラ法） | ★★★ | 時間 O((V + E) log V) | |

H × W はグリッドの大きさ、V は頂点数、E は辺の数。
