# GridShortestPath（迷路の最短距離）

難易度: ★★ / 想定時間: 25〜30分 / カテゴリ: [Search](README.md)

## 問題

文字列の配列で表された迷路が与えられる。`S` から `G` までの最短の移動回数を返す。たどり着けなければ `-1` を返す。

* `.` は通路、`#` は壁、`S` はスタート、`G` はゴール
* 1回の移動で上下左右に1マス進める。壁と迷路の外には進めない

## 入出力例

```
S.#.
.##.
...G
```

| 入力 | 出力 |
|---|---|
| 上図 | `5` |
| `["S#G"]` | `-1` |
| `["SG"]` | `1` |

上図の最短経路: S →（下）→（下）→（右）→（右）→（右）G

## ヒント

1. 迷路をグラフ（マス = 頂点、隣り合う通路 = 辺）として考える
2. 辺の重みがすべて同じとき、最短距離を求めるのに向いた探索は？
3. スタートから距離 1 のマス、距離 2 のマス……と順に広げていく → 幅優先探索（BFS）

## 解答方針

**幅優先探索（BFS）** を使う。

1. スタートの距離を 0 にしてキューに入れる
2. キューから取り出したマスの上下左右のうち、通れて未訪問のマスの距離を「今のマス + 1」にしてキューに入れる
3. ゴールを取り出したら、その距離が答え。キューが空になったら到達不能

BFS では距離の近い順にマスを訪れるので、最初にゴールに着いたときの距離が最短になる。
各マスを最大1回ずつ訪れるので、時間・空間とも **O(H × W)**。

深さ優先探索（DFS）では、最初に見つかった経路が最短とは限らない。

## 参考実装

```js
function shortestPath(grid) {
    const h = grid.length
    const w = grid[0].length
    const dist = grid.map(row => Array(row.length).fill(-1))
    const queue = []

    for (let y = 0; y < h; y++) {
        for (let x = 0; x < w; x++) {
            if (grid[y][x] === 'S') {
                dist[y][x] = 0
                queue.push([y, x])
            }
        }
    }

    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]]
    for (let head = 0; head < queue.length; head++) {
        const [y, x] = queue[head]
        if (grid[y][x] === 'G') return dist[y][x]
        for (const [dy, dx] of dirs) {
            const ny = y + dy
            const nx = x + dx
            if (ny < 0 || ny >= h || nx < 0 || nx >= w) continue
            if (grid[ny][nx] === '#' || dist[ny][nx] !== -1) continue
            dist[ny][nx] = dist[y][x] + 1
            queue.push([ny, nx])
        }
    }
    return -1
}
```

配列の `shift()` は O(n) かかる言語・実装があるので、ここでは先頭の位置 `head` を進めてキューとして使っている。

## 深掘り質問

* 最短経路そのもの（通るマスの列）を返すには？
  * 各マスに「どこから来たか」を記録し、ゴールからたどって戻る
* マスごとに移動コストが違う（例: 沼は 3）場合はどうしますか？
  * ダイクストラ法を使う。コストが 0 と 1 だけなら 0-1 BFS
* 壁を1回だけ壊してよい場合はどうしますか？
  * 「壁を壊したかどうか」を状態に加えて、(y, x, 壊したか) の空間で BFS する
