# Sort

ソートアルゴリズムの実装と、時間計算量・空間計算量の説明を求める。

## 問題一覧

| 問題 | 難易度 | 計算量（時間） | 空間 | 安定 | 詳細 |
|---|---|---|---|---|---|
| マージソートを実装する | ★★ | O(n log n) | O(n) | ○ | [MergeSort](MergeSort.md) |
| クイックソートをその場（in-place）で実装する | ★★ | 平均 O(n log n) / 最悪 O(n²) | O(log n) | × | [QuickSort](QuickSort.md) |
| バブルソートを実装する | ★ | O(n²) | O(1) | ○ | |
| 挿入ソートを実装する | ★ | O(n²)（ほぼ整列済みなら O(n)） | O(1) | ○ | |
| クイックソートを再帰を使わずに実装する | ★★★ | 平均 O(n log n) | O(log n) | × | |
| 計数ソートを実装する | ★★ | O(n + k) | O(n + k) | ○ | |
| バケットソートを実装する | ★★ | 平均 O(n + k) | O(n + k) | ○ | |
| 基数ソートを実装する | ★★★ | O(d · (n + k)) | O(n + k) | ○ | |

k は値の範囲（またはバケット数）、d は桁数。
