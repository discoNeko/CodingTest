# Anagram（アナグラム判定）

難易度: ★ / 想定時間: 15分 / カテゴリ: [String](README.md)

## 問題

2つの文字列 `s` と `t` が与えられる。`t` が `s` の文字を並べ替えたもの（アナグラム）なら `true` を返す。

* 大文字と小文字は区別する
* 空白や記号も1文字として扱う

## 入出力例

| 入力 | 出力 |
|---|---|
| `s = "listen"`, `t = "silent"` | `true` |
| `s = "rat"`, `t = "car"` | `false` |
| `s = "aab"`, `t = "abb"` | `false` |
| `s = ""`, `t = ""` | `true` |

## ヒント

1. 両方をソートして比べればわかる。計算量は？
2. 各文字が何回出てくるかを数えたら？
3. 長さが違えば、数える前に `false` とわかる

## 解答方針

| 方法 | 時間 | 空間 |
|---|---|---|
| 両方をソートして比較する | O(n log n) | O(n) |
| 文字ごとの出現回数を数えて比較する | O(n) | O(文字の種類数) |

出現回数は、`s` の文字で +1、`t` の文字で -1 すれば1つのマップで済む。最後にすべて 0 ならアナグラム。

## 参考実装

```js
function isAnagram(s, t) {
    if (s.length !== t.length) return false

    const counts = new Map()
    for (const ch of s) {
        counts.set(ch, (counts.get(ch) ?? 0) + 1)
    }
    for (const ch of t) {
        const c = counts.get(ch) ?? 0
        if (c === 0) return false
        counts.set(ch, c - 1)
    }
    return true
}
```

長さが同じなので、`t` を最後まで処理して途中で回数が足りなくならなければ、すべての回数はちょうど 0 になっている。

## 深掘り質問

* 英小文字だけとわかっているなら、どう最適化できますか？
  * マップの代わりに長さ 26 の配列を使う
* 絵文字や結合文字（例: `é` が2つのコードポイントでできている場合）があるとどうなりますか？
  * 「1文字」の定義（コードポイント / 書記素）を決める必要がある
* 単語のリストを、アナグラムどうしのグループに分けるには？
  * ソートした文字列（または出現回数）をキーにしてグループ化する
