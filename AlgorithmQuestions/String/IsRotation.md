# IsRotation（回転の判定）

難易度: ★★ / 想定時間: 20分 / カテゴリ: [String](README.md)

## 問題

2つの文字列 `s` と `t` が与えられる。`s` を回転させて `t` にできるなら `true` を返す。
回転とは、先頭から何文字かを取り出して末尾に付けること（例: `"waterbottle"` → `"erbottlewat"`）。

## 入出力例

| 入力 | 出力 |
|---|---|
| `s = "waterbottle"`, `t = "erbottlewat"` | `true` |
| `s = "abcd"`, `t = "cdab"` | `true` |
| `s = "abcd"`, `t = "acbd"` | `false` |
| `s = "aa"`, `t = "a"` | `false` |

## ヒント

1. 回転のさせ方は n 通り。全部試すと計算量は？
2. `s` を2つつなげた `s + s` には、何が含まれているか？
3. 長さが違う場合に注意

## 解答方針

| 方法 | 時間 | 空間 |
|---|---|---|
| n 通りの回転をすべて作って比較する | O(n²) | O(n) |
| `t` が `s + s` に含まれるか調べる（素朴な文字列検索） | 最悪 O(n²) | O(n) |
| 同上、KMP 法などの線形時間の文字列検索を使う | O(n) | O(n) |

`s = xy`（x と y は部分文字列）なら、回転は `yx`。`s + s = xyxy` の中には必ず `yx` が含まれる。
ただし長さが違うと `"a"` が `"aaaa"` に含まれてしまうので、先に長さを比べる。

## 参考実装

```js
function isRotation(s, t) {
    return s.length === t.length && (s + s).includes(t)
}
```

`includes` の内部実装は言語やエンジンによる。線形時間を保証したいなら KMP 法を自分で実装する。

## 深掘り質問

* `includes` を使わずに書くなら、どう実装しますか？
  * 力技で書くと O(n²)。KMP 法を知っていれば O(n) で書ける
* 何文字回転させたか（回転量）も返すには？
  * `(s + s).indexOf(t)` が回転量になる
* 配列の回転（`[1, 2, 3, 4]` → `[3, 4, 1, 2]`）でも同じ考え方は使えますか？
