# DefaultSort 想定解答

難易度: ★ / 想定時間: 15分 / 出題ファイル: [sample1.js](sample1.js)

## Q1. この関数を説明してください

得点の配列を降順に並べ、先頭から `n` 件を返す……**つもりの関数**。

* `sort()` で昇順に並べる
* `reverse()` で降順にする
* `slice(0, n)` で先頭 n 件を取り出す

## Q2. この関数に問題のある部分を教えてください

### 1. 数値が文字列として比較される

JavaScript の `sort()` は、比較関数を渡さないと**要素を文字列に変換して辞書順で並べる**。

```
topScores([80, 100, 95, 9, 72], 3)
// [95, 9, 80] を返す（正しくは [100, 95, 80]）
```

| 手順 | 結果 |
|---|---|
| `sort()`（文字列の辞書順） | `[100, 72, 80, 9, 95]` |
| `reverse()` | `[95, 9, 80, 72, 100]` |
| `slice(0, 3)` | `[95, 9, 80]` |

`"100"` は `"1"` で始まるので先頭に、`"9"` は `"8"` より後ろに来る。

### 2. 引数の配列が書き換わる（気づけると加点）

`sort()` と `reverse()` は配列をその場で書き換える。呼び出し元の `scores` も並び替わってしまう。

```
const scores = [80, 100, 95, 9, 72]
topScores(scores, 3)
console.log(scores)  // [95, 9, 80, 72, 100]
```

### その他、気づけると加点

* `n` が配列の長さより大きい、負数、小数のときの挙動が決まっていない
* `NaN` や `null` が混ざったときの並び順

## Q3. 問題の部分を解決する処理を追加してください

数値として比較する関数を渡す。降順なら `b - a` にすれば `reverse()` も不要。
元の配列を壊さないよう、コピーしてから並べる。

```js
function topScores(scores, n) {
    return [...scores].sort((a, b) => b - a).slice(0, n)
}
```

ES2023 以降なら、コピーして並べる `toSorted()` も使える。

```js
function topScoresModern(scores, n) {
    return scores.toSorted((a, b) => b - a).slice(0, n)
}
```

## Q4. この関数を汎用的にするための処理を提案してください

* **並べ替えのキーを引数化**: 数値の配列だけでなく、オブジェクトの配列から特定のプロパティで上位を取れるようにする
* **同点の扱い**: 同点のとき、元の順序を保つか（安定ソート）、同点を全員含めるか
* **引数の検証**: `n` が範囲外のときにどうするかを決める

```js
function topBy(items, n, getKey = x => x) {
    return [...items]
        .sort((a, b) => getKey(b) - getKey(a))
        .slice(0, n)
}

// topBy(users, 3, user => user.score)
```
